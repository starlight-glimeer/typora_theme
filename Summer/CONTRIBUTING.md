# Contributing Guidelines

Thank you for considering contributing to the Summer theme! Here are some guidelines to help you get started.

## How to Contribute

1. **Report Bugs**: If you find a bug, please submit an issue on GitHub with a detailed description of the problem and steps to reproduce it.

2. **Suggest New Features**: If you have ideas for new features, feel free to suggest them by submitting an issue on GitHub.

3. **Submit Pull Requests**:
   - Fork this repository
   - Create your feature branch (`git checkout -b feature/amazing-feature`)
   - Commit your changes (`git commit -m 'Add some amazing feature'`)
   - Push to the branch (`git push origin feature/amazing-feature`)
   - Open a Pull Request

## Development Guidelines

### CSS Variable Naming Convention

To maintain consistency, please follow these naming conventions:

- Use the `--` prefix to define variables
- Use hyphens to separate words
- Variable names should clearly describe their purpose

### Code Style

- Keep code indentation consistent (use 2 spaces)
- Add appropriate comments for CSS rules
- Group related style rules together

## Testing

Before submitting your changes, please make sure to test them with the latest version of Typora.

Thank you!
